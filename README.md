# Моніторинг насосних станцій

Angular-застосунок для перегляду стану станцій, витрати води, тиску, графіків і журналу сповіщень. Карта підтримує перехід до станції та масштабування колесиком миші.

## Запуск

Потрібні Node.js 22.22.3+ (версія 22) та npm.

```sh
npm ci
npm start
```

Адреса: http://localhost:4200. Демо-доступ: `admin` / `admin`.

Після зміни `angular.json` перезапустіть dev server.

## Збірка та перевірки

```sh
npm run build                  # production-збірка
npm run preview                # локальний перегляд готової збірки
npm test -- --watch=false      # модульні тести
npm run test:e2e               # браузерні тести dev-версії
npm run test:e2e:production    # збірка та браузерні тести production-версії
```

Результат збірки: `dist/monitoring/browser`. Preview: http://127.0.0.1:4200; порт має бути вільним.

Для E2E потрібен Microsoft Edge. Інший браузер можна задати через `channel` у `playwright.config.ts`.

## Деплой на Vercel

Імпортуйте GitHub-репозиторій, виберіть кореневу директорію `./` та Node.js 22. Команди встановлення, збірки, вихідна папка та SPA rewrite задані у `vercel.json`. Змінні середовища для демо не потрібні.

Або виконайте з кореня проєкту:

```sh
npx --yes vercel login
npx --yes vercel link
npm run deploy
```

Під час `link` виберіть акаунт і наявний проєкт або створіть новий; директорія коду — `./`. `npm run deploy` публікує production-версію та повертає її URL. CLI завантажується через `npx`, глобальне встановлення не потрібне.

Після деплою перевірте вхід, карту та перезавантаження `/stations/kroshnya` після входу.

## Дані та налаштування

- Дані трьох станцій синтетичні; авторизація демонстраційна, сесія зберігається в `sessionStorage`. Для реального використання потрібен backend із серверною авторизацією.
- Карта використовує OpenStreetMap і потребує доступу до інтернету.
- Правила розрахунків: `src/app/features/stations/config/stations.config.ts`.
- Кольори: `src/app/shared/config/theme.config.ts`.
